有限预算下，RL 改善的是搜索还是生成分布？

ME2502 项目工作记录，2026-11-13。这里包含既有数学恒等式在本项目中的应用与可检验假设，不声称提出了新的通用定理。原 proposal 保持不变。

1. 对应课程的最小数学问题

状态是 token 前缀与时间，动作是固定允许集合内的下一个 token，EOS 结束。最长 256 个动作，未自然结束、无效或断开的分子奖励为零。终局奖励由固定 GuacaMol v2 MPO 函数给出。γ=1 的有限时域目标不引入偏向短序列的额外折扣。生成模型是策略，不是环境转移模型。

2. 轨迹 KL 的梯度

令 τ 为包含终止行为的完整有限轨迹，pθ 是当前策略、p0 是固定初始策略。在共同支持、固定解码规则和奖励不显式依赖 θ 的条件下：

Jβ(θ) = Στ pθ(τ)[R(τ) − β log(pθ(τ)/p0(τ))] ∇Jβ = E[(R − β log(pθ/p0)) ∇log pθ] − β E[∇log pθ] = E[(R − β log(pθ/p0)) ∇log pθ] 因为 E[∇log pθ] = ∇Στ pθ(τ) = 0。

因此以 detach 后的正则化回报乘以轨迹 log-probability，得到这里使用的 score-function 估计器。额外再叠加同一 KL 惩罚会改变目标。不能只对到访前缀上的局部 KL 直接求导，就声称得到了完整轨迹目标的全部梯度；状态到访分布也会变化。

3. Baseline 与有限 batch

对独立轨迹 τi，使用其他样本的正则化回报均值 bi=Σj≠i Gj/(N−1)。条件于其他轨迹，bi 与 τi 的动作独立，所以 E[bi∇log pθ(τi)]=0。N=1 时使用历史 batch 的 baseline。计算 baseline 和 advantage 时均停止梯度。

把自己也纳入普通 batch 均值，在这个独立、同分布的轨迹估计器中，会将期望梯度缩放为 (N−1)/N；这不是一般性的方向反转，也可通过合适修正处理。我们用它作负控，是为了检查代码是否实现了声明的无偏估计器。

4. 分子与编码之间的关键区别

固定确定性映射 f 将轨迹变成 canonical 分子。无效/截断输出也必须纳入定义好的失败结果，才能讨论规范化输出分布。由 KL 链式法则：

KL(Pτ || P0τ) = KL(Pf || P0f) + Σm Pf(m) KL(Pτ|f=m || P0τ|f=m) ≥ KL(Pf || P0f)。

这说明轨迹正则能限制分子输出偏离，同时也会惩罚同一分子内部的编码概率重分配。它不意味着这部分惩罚一定很大、一定降低性能，或能够从少量采样中准确估计分子 KL。

我们已准备固定分子、多编码子集诊断：所有变体先验证解码后身份相同，再比较模型在该有限集合上归一化的概率。该值只能解释为子集条件 KL；必须同时报告子集概率质量，不能冒充全空间条件 KL 或分子 KL。

5. 训练目标与展示指标之间没有自动保证

REINFORCE 优化期望奖励，top-k 搜索评价的是尾部分布，两者不等价。一个精确反例：策略 A 永远获得 0.6；策略 B 以 1% 概率得到 1，否则为零。A 的均值 0.6 高于 B 的 0.01，但 B 在 100 次采样中的期望最高分为 0.634，高于 A；在 1000 次采样中的期望 top10 均值约 0.876，同样高于 A。

另一反例是总生成同一个满分分子：逐次均值为 1，但按十个不同候选、缺位补零的 top10 仅为 0.1。这是目标不一致的数学例子，不是我们已经观察到了模型塌缩。

固定策略、独立原始采样时，E[max]=∫(1−F(r)^B)dr。唯一分子预算和自适应训练不满足同样的 IID 假设，不能机械套公式。精确数值见 目标不一致检查。

6. 三种不同的实验结论

若历史 top10 AUC 与终态独立采样都改善，支持“候选发现与生成分布都有改善”。若只改善前者，可能是尾部候选更好，而非日常输出更好。若均值奖励升高但有效候选、骨架和独特输出下降，则需要报告集中化的代价。判断依赖实际结果，不能预设其中一种。

7. 公平预算与统计单位

每次运行至多 3000 个首次有效 canonical identity。重复样本的确定性奖励可缓存，但原始轨迹继续进入梯度；跨 run 仍各自记逻辑查询。另设总尝试、更新数和时间上限。最后 batch 的大小在采样前由剩余容量决定，不根据该 batch 的奖励筛选。搜索曲线初期不足十个候选时，缺少的 top10 位置按零补齐。

记录唯一查询轴、总尝试轴、token 与墙钟开销，不能将相同查询预算说成相同算力。提前停止时报告实际完成预算，任何固定预算 carry-forward 明确标注。

独立训练种子是方法比较的统计单位。每个模型的 1024 个终态样本用于刻画其输出，不能被当成 1024 次独立训练。三个种子只能支持有限的稳定性判断；报告全部种子、配对差异与离散程度，不依靠漂亮的均值或伪重复获得显著性。
